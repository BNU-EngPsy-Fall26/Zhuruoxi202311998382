# 信号检测论 · 交互式实验室

《工程心理学》作业一：构建一个信号检测论（SDT）交互式实验网站。

本作品设计了两个 SDT 检测场景（《隔离区哨岗》《老宅巡夜》），实现逐试次、限时的信号检测游戏，结束后自动计算并展示完整 SDT 指标；另附**概念实验室**（交互式概念可视化）与**数据查看**（多局记录、排行榜与散点图）两个扩展模块。

整体采用暗黑恐怖视觉主题：场景氛围图虚化背景、胶片噪点、黑化磨砂面板、暗红辉光标题与哑光奖牌，营造沉浸式"深夜实验"氛围。

## 运行方式

纯前端实现（HTML + CSS + JavaScript，SVG 绘制游戏画面），**无需任何依赖、无需后端、无需构建**：

1. 双击打开 `index.html` 即可在浏览器中运行（推荐 Chrome / Edge）；
2. 登录（任意姓名 + 学号）→ 选择角色 → 完成一局游戏即可看到 SDT 结果；
3. 主界面底部可进入「概念实验室」与「数据与排行榜」。

## 一、场景与参数定义

**场景 A 《隔离区哨岗》**：夜视画面中 2~4 个人影走向闸门，其中可能混着僵尸。
- 信号 S = 僵尸；噪音 N = 幸存者。
- 说"有"= 开枪警戒；说"无" = 放行。
- 击中 = 命中混入的僵尸；漏报 = 放僵尸进隔离区（后果最严重）；误报 = 错伤幸存者；正确拒斥 = 幸存者安全通过。

**场景 B 《老宅巡夜》**：凌晨的镜子中浮现 2~4 张人脸，其中可能混着鬼。
- 信号 S = 鬼；噪音 N = 房客。
- 说"有"= 离开老宅；说"无" = 留宿。
- 击中 = 识破鬼并逃过一劫；漏报 = 留在有鬼的宅子里；误报 = 错怪房客仓皇逃离；正确拒斥 = 安心留宿。

**参数设定**（游戏开始前的说明页与主界面均有展示）：
- **先验概率 P(S) = 0.5**：每局恰好一半试次有信号，顺序随机打乱；
- **难度 d′ 滑块（0.5 困难 ~ 3.5 简单）**：d′ 越低，目标的可辨识线索越微弱、与噪音越重叠；每轮实际 d′ 在设定值 ±0.6 内随机波动（更贴近真实检测情境）；
- **试次数**：课堂版 20 次 / 课后长版 100 次（每局 ≥ 20 试次）；
- **刺激限时**：场景 A 每轮呈现 2.5 s、场景 B 2.2 s，画面消失后才出现判断按钮，迫使被试在有限证据下做判断；
- 四种结果的实际含义在游戏说明页以表格显式列出，且每次判断后均有场景化即时反馈（漏报另触发全屏警示视频）。

## 二、交互式检测游戏

- 两个场景均为**逐试次判断**：呈现刺激（限时）→ 画面消失 → 二选一判断 → 即时反馈 → 下一轮；
- 画面每轮随机生成：场景 A 人影的高矮、步态、姿态、僵尸线索强度（手臂前伸角 / 头颈耷拉程度 / 移动速度）逐轮随机，僵尸分四型（举手型 / 垂头型 / 迟缓型 / 混合型），无法靠单一特征背题；场景 B 人脸的大小、倾斜、表情、发型逐轮随机，鬼脸分四类（表情阴翳 / 仅肤色微差 / 五官倾斜 / 双重线索），人脸与鬼脸位置零重叠；
- 信号强度 k 随本轮 d′ 连续变化，保证"难度滑块"真实改变刺激可辨识度；
- 漏报触发专属全屏警示视频（用户提供素材，完整播放后自动继续，不中断统计）。

## 三、结果计算与展示

一局结束后展示：

- **混淆矩阵**：击中 H / 漏报 M / 误报 FA / 正确拒斥 CR（自动统计）；
- **SDT 指标**：击中率 P(H)、误报率 P(FA)、辨别力 d′、判断标准 c、准确率；
- 附"为什么光看准确率不够"对照思考区（同为 75% 准确率的谨慎型 vs 宽松型被试）。

**计算口径**（与概念实验室一致）：
- 比例做 +0.5 对数线性校正：P = (次数 + 0.5) / (n + 1)，避免 0/1 导致 z 分数无穷大；
- z 分数用 Acklam 逆正态近似；
- d′ = z(P(H)) − z(P(FA))；c = −[z(P(H)) + z(P(FA))] / 2；
- 排行榜中另附面积法敏感度 A′（Pollack & Norman, 1964）。

## 四、概念实验室（加分项：交互式概念可视化）

- **两个分布与判定标准**：d′ 与 c 双滑块实时联动信号/噪音分布图，误报区、漏报区着色；鼠标悬停曲线任意位置显示该判定下的漏报/误报概率；同步展示理论混淆矩阵与 P(H)/P(FA)/d′/c/β/A′；场景预设：自由探索、隔离区哨岗、老宅巡夜、医疗诊断；
- **ROC 曲线**：d′ / c / 信号方差 σ²(SN) 三滑块联动 ROC 曲线与 z 变换 ROC（直线，斜率随方差变化），红点标出当前工作点；实时计算 P(H)/P(FA)/AUC（数值积分），并说明"同一条 ROC 曲线 = 相同 d′、不同标准，0.5 = 随机，1.0 = 完美"；
- **标准与奖惩**：先验概率 P(信号) 与支付矩阵 V(H)/C(M)/C(FA)/V(CR) 均可调，实时计算当前 β、期望收益与收益最大化的最优标准 β*/c*，分布图上同时标出当前 c（红实线）与最优 c*（金虚线）。

## 五、数据查看（加分项：多局数据对比与排行榜）

- **我的表现记录**：当前用户全部对局（时间、游戏、试次、H/M/FA/CR、准确率、P(H)、P(FA)、d′、c）；
- **全体排行榜**：本机所有被试 × 游戏取最佳一局，按准确率 → d′ 排序，前三名奖牌徽章，当前用户金色高亮；超过 10 行自动滑动；
- **数据可视化**：d′–c 散点图 + P(FA)–P(H) 操作点图（SVG 绘制），鼠标悬停显示该点的姓名、游戏与全部指标；
- 数据经 localStorage 持久化（仅存姓名，不存学号）；支持一键载入示例数据（课堂演示）、导出 JSON、清空重测。
